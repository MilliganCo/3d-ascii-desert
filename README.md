# Пустыня: Вода как валюта

3D ASCII игра на выживание в пустыне, где вода является главным ресурсом и валютой.

## Установка

```bash
pip install -r requirements.txt
```

## Запуск

```bash
python main.py
```

## Управление

- WASD или стрелки - перемещение
- E - взаимодействие с объектами
- I - инвентарь
- ESC - меню

## Особенности

- Изометрическая ASCII графика
- Процедурно генерируемый бесконечный мир
- Реалистичные физические системы (гидродинамика, метеорология, экология)
- Динамическое изменение мира в зависимости от уровня воды
- Система торговли с водой как валютой
